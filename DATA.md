# Data

paved ships no third-party datasets. All data in the repository is **synthetic and authored for
this project**:

| Data | Path | Source | License |
|---|---|---|---|
| Fixture monorepo (catalog descriptors, READMEs, CI files, manifests) | `fixtures/acme-monorepo/` | written by hand for this repo; the organisation "Acme", its teams and services are fictional | MIT (this repo) |
| Package-registry snapshot (versions + release dates) | `fixtures/acme-monorepo/.paved/registry.yaml` | invented; package names use the reserved `example.com` domain and fictional `@acme` / `acme-*` namespaces | MIT (this repo) |
| Golden outputs | `internal/scaffold/testdata/golden/`, `internal/scorecard/testdata/` | generated by paved itself (`go test ... -update`) | MIT (this repo) |
| Generated benchmark catalogs | in-memory only (`genCatalog` in `internal/catalog/query_test.go`) | seeded pseudo-random generator | n/a |

Consequences: scorecard numbers in the README describe the fixture, not any real organisation;
libyear values are only as meaningful as the invented release dates. No data is downloaded at
build, test or demo time.
